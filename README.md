⚡ Shree Electrical Service Management System

📌 Project Overview

The Electrical Service Management System is a web-based application designed to manage electrical services, customers, service requests, billing, payments, and service history. It provides a user-friendly interface for customers and a dashboard for the owner to manage business operations efficiently.

✨ Features

Home Page: Displays information about the electrical service business.

Services Management: Displays available electrical services.

Customer Management: Maintains customer details and records.

Customer Login: Allows customers to access their dashboard.

Owner Login: Provides secure access to the owner dashboard.

Dashboard: Displays important business information.

Service Orders: Manages customer service requests and orders.

Billing System: Generates and manages customer bills.

Payment Tracking: Tracks customer payment status.

Revenue Management: Displays revenue-related information.

Service History: Maintains records of previous services.

Responsive Design: Provides a user-friendly interface across different screen sizes.

🚀 How to Run the Project

Download or clone the repository from GitHub.

Open the project folder in Visual Studio Code.

Configure Firebase in js/firebase.js.

Ensure Firebase Authentication and Cloud Firestore are configured correctly.

Open the project using the Live Server extension in Visual Studio Code.

Open index.html in your browser.

Use the website to explore the available services and features.

🔥 Firebase Configuration

Create a project in the Firebase Console.

Register a web application.

Enable Firebase Authentication.

Configure Cloud Firestore.

Add the Firebase configuration to js/firebase.js.

Set appropriate Firestore security rules to protect customer information.

🌐 Deployment

The website can be hosted using GitHub Pages.

Upload the project files to a GitHub repository.

Open the repository's Settings.

Select Pages.

Choose Deploy from a branch.

Select the main branch and / (root) folder.

Click Save.

Open the published website URL after deployment completes.

Note: GitHub Pages hosts the frontend. Firebase must be configured separately for authentication and database functionality.

🔐 Security

Protect customer information using appropriate Firebase security rules.

Do not upload passwords or private service-account keys to GitHub.

Use Firebase Authentication to manage authorized access.

Avoid storing sensitive customer information in a public repository.
